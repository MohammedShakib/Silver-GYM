# Silver GYM

Full-stack starter project with React (Vite) frontend and Express backend.

## Folder Structure

```text
Silver-GYM/
  frontend/   React client application
  backend/    Express API application
```

## Run Locally

Install dependencies are already generated in both apps. Start both apps from the root:

```bash
npm run dev
```

Frontend: `http://localhost:5173`

Backend: `http://localhost:5000/api/health`
